# Antislop audit 003: dashboard UX consolidation

The user explicitly requested browser verification, a review of unassigned costs, and removal of redundant UI. This authorizes the corresponding UX changes without a separate numbered-approval request. x.ai-inspired monochrome styling, self-hosted Geist, the supplied KU Creatives logo, and the explicitly requested Lucide icons are retained.

## Implemented changes

- PASS, source check, R-26/C-3: import exists only on Sources & import; export exists only in the transaction toolbar; the theme toggle exists only in the global top bar; retry is conditional on pending messages.
- PASS, source check, hierarchy: transaction search, project/status filters, and export are grouped in one toolbar. Selecting unresolved clears/hides the incompatible project filter. Export uses those visible filters.
- PASS, source check, C-3: removed page eyebrows/subtitles, workspace card, sidebar helper notes, footer notes, duplicate metric totals above the chart, duplicated metrics on Projects, explanatory table footer, and duplicated unresolved banners.
- PASS, source check, disclosure: source configuration, conversion rates, diagnostics, and the mock inbox are available on demand. Alert summaries are not duplicated as two visible message feeds.
- PASS, source check, R-32: a native modal replaces per-row dropdown/save controls. It exposes full IDs, amount, tool, source label, project, and duplicate reference. It has a labeled title, close/cancel controls, required project selection, native Escape dismissal/focus containment, inline save errors, and focus restoration.
- PASS, source check, R-27: loading, empty, API-error, zero-search-results, disabled import/save/export, and pending notification states remain implemented.
- PASS, data review: all 13 originally unresolved source records reviewed. One pre-existing BRK-05 assignment preserved; 12 remaining records total Rp5,201,507.50. No new accounting assignments or other financial mutations were made. Evidence: docs/unassigned-review.md.
- PASS, automated app verification: seven existing tests pass, including four-source reconciliation, idempotency, persistent assignments, rollback, webhook delivery, and the HTTP application boundary. JavaScript syntax and git whitespace checks pass. This is not evidence of a browser walkthrough.
- PASS, research-backed decisions: references and applied decisions are in docs/ux-decisions.md (GOV.UK primary actions, Carbon table toolbar, NN/g progressive disclosure).
